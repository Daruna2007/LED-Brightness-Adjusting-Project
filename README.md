# **LED Brightness Adjusting Project**

## **1\. Aim**

To build a simple circuit that lets the user manually vary the brightness of an LED, using a potentiometer, a resistor, an LED, and a power source. 

## **2\. Problem Statement**

Many basic electronic circuits need an LED whose brightness can be set to suit the user. A fixed resistor gives a constant current, so the brightness stays the same and cannot be changed. A potentiometer, acting as a variable resistance, solves this by letting the user change the current through the LED .

## **3\. Proposed Solution**

The circuit uses a potentiometer to regulate how much current reaches the LED.  
Turning the knob changes the resistance in the circuit, which raises or lowers the LED current and so makes it glow brighter or dimmer. It is a low-cost, easy way to demonstrate variable resistance, current control, and LED behaviour 

## **4\. Components Required**

1. LED  
2. Potentiometer  
3. Resistor  
4. Breadboard  
5. Battery / DC Power Supply  
6. Jumper Wires

## **5\. Circuit Working**

The LED is powered through a fixed resistor and a potentiometer connected in series. The fixed resistor limits the current and keeps the LED safe from damage, while the potentiometer supplies the adjustable resistance.

When the knob is turned:

* Higher resistance means lower current, so the LED becomes dimmer.  
* Lower resistance means higher current, so the LED becomes brighter.

Hence, the brightness is controlled manually by rotating the potentiometer

## **6\. Procedure**

1.Place the components on the breadboard following the circuit diagram.  
2.Join the positive terminal of the supply to the circuit.  
3.Insert the LED with the correct polarity (anode towards positive).  
4.Connect the resistor in series with the LED to limit the current.  
5.Wire the potentiometer into the circuit to vary the resistance.  
6.Connect the circuit's ground line to the negative terminal of the supply.  
7.Recheck every connection before applying power.  
8.Turn the power supply ON.  
9.Slowly rotate the potentiometer in both directions.  
10.Watch how the LED brightness changes

## **7\. Applications**

* 💡 **Lighting control:** adjusting the brightness of indicator or decorative LEDs.  
* 🎛️ **Control systems:** shows how a potentiometer gives variable control.  
* 🏫 **Learning projects:** helps students grasp resistance, current, and LED operation.  
* 🔧 **Prototyping:** handy for testing dimmable lighting circuits.  
* 🚦 **Indicators:** can be adapted for indicators with adjustable brightness

## **8\. Advantages**

* 🎛️ Gives hands-on brightness control.  
* ⚡ Inexpensive to make.  
* 🔧 Quick to assemble on a breadboard.  
* 🧑‍🎓 Well suited to beginners and classroom demonstrations.  
* 🔄 Brightness changes smoothly across the whole range


## **9\. Result**

The LED brightness control circuit was built and tested successfully. Rotating the potentiometer changed the resistance and the current through the LED, and the brightness changed accordingly. 

## **10\. Conclusion**

This project demonstrates how a potentiometer can control LED brightness. It gives practical insight into resistance, current, voltage, and how an LED behaves in a circuit, making it a straightforward and effective way to learn how variable resistance controls an electronic component.
